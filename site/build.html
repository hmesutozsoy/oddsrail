Agent builder

Tick the pieces. Read the prompt. Send it to Claude.

Every box below is a strategy fragment or a risk rule written with the right oddsrail tools in the right order. They compose into one prompt you can edit, then run in Claude with the oddsrail connector. Paper by default; nothing here needs a key.

Claude runs one pass per message. For an agent that keeps going, run the same prompt on a schedule with the self-hosted plugin, or ask Claude to run another pass.

Open in Claude

Open in Claude starts a new chat with the prompt filled in. Make sure the oddsrail connector is enabled in that chat (Settings, Connectors) or the tools will not be there. In Claude Code, paste the prompt with the hosted server added by claude mcp add --transport http oddsrail https://mcp.oddsrail.app/mcp.

What the boxes cannot do

  • Stop losses are review rules, not orders. Polymarket has no stop orders. A stop here means: at each review, if the mark is below your threshold, sell at the bid. Between reviews nothing protects you.
  • Paper is an upper bound. Fills are simulated from the live book with no queue, no impact and no fees, and paper does not pay out at resolution; it marks at the mid.
  • Two-sided quoting looked fine on paper for us too. The maintainer's own market-making engine lost about 4.5 cents per share on markout live at small size. The fragment ships with that warning inside the prompt.
  • check_order is always on. Every fragment routes each order through it with your intent verbatim, and a block is final. That is the one piece you cannot untick.
